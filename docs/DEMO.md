# Demo video script (about 2 minutes 30 seconds)

Record the screen with system audio on, so the app's voice is heard. This script doubles as the transcript and captions for the video.

| Time | On screen | Say (voice-over) |
|---|---|---|
| 0:00 | Listen tab, quadratic formula typed in | "This is how a screen reader reads typed maths." |
| 0:05 | Press **Hear the before** | *(app plays: "x equals left paren dash b plus s q r t…")* |
| 0:15 | | "Try holding that in your head. Blind students do this for every equation. SayMath reads it like a teacher would." |
| 0:22 | Press **Hear again** | *(app: "x equals the fraction with numerator negative b plus the square root of b squared minus 4 a c, end root, and denominator 2 a, end fraction")* |
| 0:35 | Click the equation, press ↓ → → ↓ → | "And you can explore it. Down goes inside, right moves along. Here's the denominator: 2 a." |
| 0:50 | Press **An ambiguous one** | "If what you typed could mean two things, like one over 2x, SayMath says so instead of guessing." |
| 1:00 | Practice tab. Type `x = 5`, Check | "Practice by ear. It reads your answer back, so you know it heard you, and tells you why it isn't right." |
| 1:15 | Hint, then type `8/2`, Check | "Ask for a hint. 8 over 2 is 4, so it counts." |
| 1:25 | Settings → हिन्दी, Hear the problem | "The same maths in Hindi, for students in Hindi-medium schools." *(app speaks Hindi)* |
| 1:40 | Teach tab, add `1/2x` line | "Teachers type questions, and SayMath flags anything a listener could misunderstand." |
| 1:50 | Download worksheet; turn off Wi-Fi; open file on phone | "One click makes a 53 KB file. Send it on WhatsApp. It works with no internet: it reads, explores and checks answers." |
| 2:10 | Settings: extra-large text, high contrast | "Large text, high contrast, and it works offline after one visit." |
| 2:20 | README limitations | "What's next: testing with blind students and Hindi teachers, and reading equations from photos. SayMath: maths you can hear." |
