Type math. Hear it clearly.

Screen readers often read typed math as a string of symbols. SayMath reads it the way a teacher would, and tells you where every fraction, root and bracket ends.

Use ^ for powers, / for fractions, sqrt( ) for roots, _ for subscripts. Press Enter to hear it.

More: calculus, matrices, ±
  • sum(i=1, n, i^2), prod(k=1, n, k)
  • int(x^2, x), int(x^2, x, 0, 1)
  • lim(x -> 0, sin(x)/x), diff(x^3, x), diff(y, x, 2)
  • [[1, 2], [3, 4]], det([[1, 2], [3, 4]])
  • +/- or ±, 30°, ~= or ≈, asin cosh…

    Make an offline worksheet

    Type your questions. SayMath checks every line and flags anything a listener could misunderstand. It then builds one small file that opens on any phone or computer with no internet. Students can hear each question, explore it with the keyboard and check their answers.

    One question per line. You can start with words and a colon (Solve for x:) and end with answer: x = 5.
